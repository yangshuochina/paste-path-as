# Changelog

## 1.0.1

- Add Wrap Selection with #if 0, available from the Command Palette and editor context menu.
- Add Ctrl+Alt+0 (macOS: Cmd+Alt+0).
- Support whole-line wrapping, merged overlapping selections, preserved line endings, and single-step undo.

## 1.0.0

- Paste clipboard text as original Windows paths, escaped backslashes, or forward slashes.
- Command Palette and editor context menu integration.
- Ctrl+Alt+V shortcut on Windows and Linux; Cmd+Alt+V on macOS.
- Selection replacement, multiple cursors, and single-step undo.
